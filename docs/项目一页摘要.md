# aiQAsystem 一页摘要（v1.0.0 · final）

## 一句话介绍
面向企业文档（PDF/Word/Excel/TXT/MD）的智能问答系统：**上传文档即可提问，答案准确、有出处、可追溯**。

## 技术栈
FastAPI + LangChain 文本切片 + Chroma 向量库 + 本地 Embedding（bge-small-zh）+ DeepSeek + Streamlit + SQLite

## 核心流程
上传校验 → 五格式解析（页码/工作表/章节溯源）→ 结构化切片 → 向量入库 → 语义检索（阈值 0.485）→ Prompt 渲染 → DeepSeek 生成 → 程序生成连续引用 → 落库（多轮/反馈/会话）

## 功能清单
- 文档管理：上传（格式/大小校验、失败隔离）、列表过滤、级联删除
- 问答：带连续引用编号、原文可核对、无依据拒答（零编造）、多轮追问改写、流式输出
- 体验：会话历史、点赞点踩反馈、问答导出 Markdown、首次检索预热提示
- 运维：一键启动/停止、健康检查（四项依赖）、日志归档、压测脚本

- 自动化：单元测试 140 项 + 前端自测 36 + 契约检查 10 + 实测联调 51 项，全部通过
- 评测体系：20 条单轮评测集 + 8 例多轮用例 + 多采样稳定性 + A/B 对比脚本
- 安全：`.env` 不入库、日志密钥脱敏、越界引用剔除、防编造降级策略
