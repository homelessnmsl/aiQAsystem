# 演示部署说明（一键启动 · 答辩环境）

> 任务：W4-02 / W4-06 ｜ 适用：答辩演示、组内联调 ｜ 维护：DEV

## 一、一键启动（推荐）

```powershell
# 在仓库根目录执行
powershell -ExecutionPolicy Bypass -File scripts\start_demo.ps1
```

脚本自动完成：环境检查 → 启动后端（uvicorn，默认 8000）→ 健康检查（四项依赖）→
检索预热（加载本地向量模型，约 10~15 秒）→ 启动前端（Streamlit，默认 8501）→ 打开浏览器。

常用参数：

| 参数 | 说明 |
| :--- | :--- |
| `-BackendPort 8000` / `-FrontendPort 8501` | 自定义端口（联调去冲突用） |
| `-SkipWarmup` | 跳过预热（知识库为空时自动跳过） |
| `-NoBrowser` | 不自动打开浏览器（投屏 / 自动化场景） |
| `-ForceRestart` | 重启"由本脚本启动过"的后端进程 |
| `-Stop` | 停止本脚本启动的后端与前端 |

停止服务：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\start_demo.ps1 -Stop
```

- 日志目录：`data\logs\demo\`（后端主日志为 `backend.err.log`，前端为 `frontend.err.log`）
- 进程 PID：`data\logs\demo\pids.json`（供 `-Stop` 使用）

## 二、分步启动（后备方案）

```powershell
# 终端 1：后端（仓库根目录）
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
# 终端 2：前端
.venv\Scripts\python.exe -m streamlit run web/app.py --server.port 8501
```

## 三、答辩当天 1 分钟检查清单

1. 执行 `start_demo.ps1`，看到"**健康检查通过**"与"**预热完成**"（否则按提示查 `.env` / 知识库）；
2. 浏览器打开问答页，问一句"公司年假有多少天？"确认**带引用回答**；
3. 断网兜底：页面左侧切"演示模式"验证预置问答（详见 `docs/演示脚本.md`）；
4. 备用问答清单与分镜走查见 `docs/演示脚本.md`。

## 四、常见问题（排障）

| 现象 | 处理 |
| :--- | :--- |
| 端口被占用（8000 / 8501） | 脚本会复用现有监听；**若为历史遗留的旧进程，请先结束它再启动**（`-ForceRestart` 只能重启本脚本启动过的进程），或换端口：`-BackendPort 8001 -FrontendPort 8502` |
| 首问很慢（> 10 秒） | 本地向量模型冷启动（已知项）；脚本已内置预热；跳过预热时先手动问一句 |
| `/api/ask` 返回 3003 | `.env` 未配置 `DEEPSEEK_API_KEY`（复制 `.env.example` 并填写） |
| 知识库为空（chunk_count=0） | 执行 `python scripts/init_kb.py` 导入样例，或在"知识库管理"页上传 |
| 后端检索突然异常 / 句柄失效 | **Chroma 持久目录不支持多进程并发**：后端运行期间不要再用离线脚本（`eval_rag.py --mode offline`、`init_kb.py` 等）直连 `data/chroma`；两者二选一，或离线跑完后重启后端（`-ForceRestart`，或 `-Stop` 后重新启动） |
| 需要完全重来 | `start_demo.ps1 -Stop` → 结束所有离线脚本 → 重新执行 `start_demo.ps1` |

> "离线脚本与后端二选一"的约定来自 PE 质量报告 R5（2026-10-09），作为答辩运维注意事项执行。
