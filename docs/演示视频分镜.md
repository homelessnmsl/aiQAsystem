## 1. 录制规格

| 项 | 要求 |
| :--- | :--- |
| 分辨率 / 帧率 | 1920×1080 / 30fps（笔记本屏幕不够就 1600×900，保证文字清晰） |
| 时长 | 主视频 5 分钟（4:30~5:30 之间）；离线备用版 ≤1 分钟 |
| 画面范围 | **只录浏览器窗口**（不要录整个桌面），避免露出 `.env`、聊天窗口、其他项目文件 |
| 字幕 | 全程中文硬字幕（关键操作与结论），答辩现场即便静音也能看懂 |
| 音量 | 口播清晰即可；若现场不配音，用字幕 + 关键点解说替代 |
| 工具 | Windows 自带 Xbox Game Bar（`Win+G`）或 OBS；不额外安装软件到答辩机 |
| 文件命名 | `aiqa_演示_主视频_v1.mp4`、`aiqa_演示_离线备用_v1.mp4` |

> **安全提醒（NFR-S-01）**：录制前关闭所有含 API Key 的终端/编辑器窗口，浏览器只留两个标签页（问答页、知识库管理页），关掉书签栏与通知。

## 2. 录制前准备（与演示脚本一致，按顺序做完再开录）

| # | 操作 | 判定标准 |
| :--- | :--- | :--- |
| 1 | 启动后端（8000）与前端（8501） | 侧栏"服务连接"显示**后端连接正常**，四项依赖全绿 |
| 2 | **预热一句**："公司年假有多少天？" | 首次检索需加载本地模型约 10~15 秒，必须提前消耗掉 |
| 3 | 跑一次自检 | `.venv\Scripts\python.exe web/live_check.py` 输出 37/37 |
| 4 | 清场 | 关掉含 Key 的窗口、关通知、浏览器 100% 缩放、两个标签页就位 |
| 5 | 试录 10 秒 | 确认画面清晰、字幕位置不挡内容 |

## 3. 主视频分镜表（5 分钟）

| 镜号 | 时长 | 画面 | 操作 | 字幕要点 | 口播要点 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| S1 | 0:00-0:20 | 问答页全景 | 静止 | 企业知识库智能问答系统 · 上传文档即可提问 | 系统定位：面向企业文档的问答助手，答案带出处 |
| S2 | 0:20-0:50 | 知识库管理页顶部 | 指向四个指标 | 10 份文档 / 31 个切片 / 五种格式 | 知识库覆盖情况一眼可见 |
| S3 | 0:50-1:20 | 上传区 | 选择 `05_常见问题FAQ.md` → 点"开始上传" → 展示步骤态与结果 | 自动解析 → 切片 → 向量化入库 | 多文件逐个处理，单个失败不影响其他文件 |
| S4 | 1:20-2:20 | 问答页 | 提问**"公司年假有多少天？"** → 等答案逐字出现（流式）→ 指出「已找到依据」徽章 → 展开引用条 | 流式回答：边生成边显示 · 引用：01_员工手册.pdf · 第 3 页 | 答案逐字出现，等待感更弱；点开引用就是原文 |
| S5 | 2:20-2:50 | 问答页 | 提问**"出差住宿标准是多少？"** → 展开引用 | Excel 取数：工作表「差旅标准」第 2~4 行 | 表格里的数值也能溯源 |
| S6 | 2:50-3:30 | 问答页 | 提问**"试用期转正要走哪些流程？"** → 追问**"审批环节有几个？"** | 多轮追问：沿用上文，不用重复背景 | 对话能记住上下文 |
| S7 | 3:30-3:50 | 回答下方 | 点 👎 → 填"答案没有给出天数" → 提交 | 每条回答可反馈，反馈失败不影响问答 | 反馈会落库，用于持续改进 |
| S8 | 3:50-4:10 | 侧栏 | 展开「历史会话」→ 点回上一条会话 → 展示回显的引用 | 历史会话可切回，引用一起回显 | 记录不会丢，方便回看 |
| S9 | 4:10-4:30 | 侧栏 | 点"导出本会话（Markdown）"→ 展示下载的 md 片段 | 会话可导出为 Markdown（含问答与引用） | 便于留档与写进报告 |
| S10 | 4:30-4:55 | 问答页 | 提问**"公司食堂几点开饭？"** → 展示兜底提示 | 知识库没有的问题：明确说"没找到"，不编造 | 拒答正确率 100%，宁可不答不可编造 |
| S11 | 4:55-5:20 | 收尾 | 切回知识库页 → 定格指标 | 检索命中率 100% · 引用准确率 100% · 答案正确率 93.3% · 拒答正确率 100% | 一周内从零搭到可用，全链路带引用 |

**3 分钟精简版**（若答辩限时）：S1 → S2 → S4 → S5 → S10 → S11。

## 5. 录制后检查清单

- [ ] 主视频 5 分钟内讲完，无卡顿超过 5 秒的片段（首次检索已预热）

- [ ] 离线备用版可独立播放并看懂完整流程
- [ ] 两个 mp4 已上传共享位置，链接登记在本文件第 6 节
