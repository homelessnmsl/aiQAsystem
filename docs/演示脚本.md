## 1. 演示前准备（提前 2~5 分钟做完）

| 步骤 | 操作 | 检查点 |
| :--- | :--- | :--- |
| ① 启动后端 | `.venv\Scripts\python.exe -m uvicorn app.main:app --port 8000` | 浏览器打开 `http://127.0.0.1:8000/docs` 能出 Swagger |
| ② 启动前端 | `.venv\Scripts\python.exe -m streamlit run web/app.py` | 打开 `http://127.0.0.1:8501` |
| ③ 自检 | `.venv\Scripts\python.exe web/live_check.py` | 输出 `37/37 项通过`；若后端没起，输出会明确提示 |
| ④ **预热一句**（关键） | 在问答页问"公司年假有多少天？" | 首次提问要加载本地向量模型约 10~15 秒，**先说一句暖机**，别让评委看到卡顿 |
| ⑤ 准备标签页 | 问答页 + 知识库管理页各开一个标签 | 演示时直接切换，不现场敲地址 |
| ⑥ 兜底准备 | 手机热点/离线时改开「演示模式」；提前截好关键步骤图 | 断网也能讲完流程 |

> 侧栏"服务连接"显示**后端连接正常**且四项依赖全绿，才算准备好。

## 2. 演示分镜（5 分钟版）

| # | 时长 | 操作 | 说给观众的话（要点） |
| :--- | :--- | :--- | :--- |
| 0 | 20s | 切到问答页 | "这是面向企业文档的智能问答系统：上传制度文档，员工用大白话提问，答案会标明出处。" |
| 1 | 30s | 切到知识库管理页，指顶部四个指标 | "目前知识库有 10 份文档、31 个切片，覆盖 PDF / Word / Excel / TXT / Markdown 五种格式。" |
| 2 | 40s | 上传 `tests/sample_docs/05_常见问题FAQ.md` | "上传后自动解析、切片、向量化入库；多文件逐个处理，单个失败不影响其他文件。"（展示步骤态与逐文件结果） |
| 3 | 60s | 回问答页，问**"公司年假有多少天？"** | 指出三态徽章「已找到依据」→ 答案是分档要点式 → 点开引用条 **[1] 01_员工手册.pdf · 第 3 页**，"点开就是原文，不用下载文件"（FR-CIT-03） |
| 4 | 30s | 问**"出差住宿标准是多少？"** | 强调**表格取数**：引用定位到 **工作表「差旅标准」第 2~4 行**，"Excel 里的数值也能溯源"（US-06） |
| 5 | 40s | 问**"试用期转正要走哪些流程？"**，再追问**"审批环节有几个？"** | 强调多轮对话：第二轮沿用上文，不用重复背景（US-07） |
| 6 | 20s | 对上一条回答点 **👎 不准确**，填"答案没有给出天数"后提交 | "每条回答都能反馈，反馈会落库；反馈失败也不影响问答主流程"（US-12） |
| 7 | 20s | 侧栏展开「历史会话」，点回上一条会话 | "历史会话可切回，引用一起回显"（US-13） |
| 8 | 30s | 问**"公司食堂几点开饭？"** | "知识库里没有这个问题，系统**明确说没找到**，不编造——这是我们的拒答指标 M-04"（US-08） |
| 9 | 20s | 打开侧栏「演示模式」 | "如果现场网络异常，可以切演示模式，用预置问答把流程讲完"（US-14） |
| 10 | 30s | 收尾，展示指标 | "第2周评测：检索命中率 100%、引用准确率 100%、答案正确率 93.3%、拒答正确率 100%。" |

**3 分钟精简版**：0 → 1 → 3 → 4 → 8 → 10（跳过上传、多轮、反馈、历史、演示模式）。

## 3. 风险与应急预案

| 情况 | 现象 | 现场应对 |
| :--- | :--- | :--- |
| 首次检索慢 | 转圈 10~15 秒 | 已在界面提示"首次使用要加载检索模型"；**必须提前预热一句** |
| 模型限流/超时 | 提示"回答生成超时/模型服务繁忙" + 重试按钮 | 点「重试这次提问」；连续失败则切演示模式 |
| 后端没启动 | 侧栏"后端未连接"，提问给中文错误 | 现场启动后端（10 秒即可）；或切演示模式 |
| 断网 | 同上 | 切演示模式，强调"这正是我们设计演示模式的原因" |
| 引用位置对不上 | 引用文件与答案不符 | 用"公司食堂几点开饭？"演示兜底；把问题记下来交给 RA 进缺陷清单 |
| 现场设备异常 | 页面打不开 | 用提前截好的关键步骤图 + 录屏讲流程 |
