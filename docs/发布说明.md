# 发布说明（aiQAsystem v1.0.0 · tag final）

- 发布日期：2026-10-09
- 版本：v1.0.0（`master` 分支，tag `final`）

## 快速开始

```powershell
cd C:\Users\HP\Desktop\aiQAsystem
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
.\scripts\start_demo.ps1            # 一键启动后端(8000)+前端(8501)，自动预热
.\scripts\start_demo.ps1 -Stop      # 一键停止
```

访问：前端 http://127.0.0.1:8501，API 文档 http://127.0.0.1:8000/docs

## 已包含能力

上传（PDF/Word/Excel/TXT/MD）→ 解析入库 → 语义检索 → 带连续引用编号的答案（可溯源原文）→ 多轮追问 → 会话/反馈 → 流式输出 → 删除文档 → 一键部署。

## 运维注意

- 首次检索需加载本地向量模型约 10~15 秒（启动脚本已自动预热）
- Chroma 数据目录不支持多进程并发：评测脚本与后端服务不要同时直连同一目录（见 scripts/README.md）
- 模型下载：本机网络受限时用 `scripts/download_model.py`（魔搭源）
