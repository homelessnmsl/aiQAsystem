## 3. 主要发现

### 3.1 M-02 的"自动预检"低于人工结论，属于口径差异，不是引用错误

自动预检（69.6% → v1.1 后 76.2%）把"引用编号与本题唯一期望来源不一致"一律记为不通过；人工复核发现，
实际存在的第二种模式是**额外引用相关文档来支撑补充说明**，例如 QA-001 用 FAQ 片段支撑"年假申请流程"、
QA-009 用《入职培训指南》"转正后享受正式员工全部福利"支撑补充句——均属正确引用。

但自动预检暴露了两个真实问题（列入跟进表）：

- **位置标签粒度过粗**：`05_常见问题FAQ.md` 的切片位置写作「章节『员工常见问题 FAQ（2026 版）』~『…4. 如何申请 VPN 权限？』」，
  `07_客户支持服务流程.docx` 写作「章节『四、工单处理流程』~『六、服务考核』」，跨度过大，不满足 FR-CIT-02 对精确位置的要求。

### 3.2 QA-005 不完整是"检索召回"问题，不是生成问题（已定位到具体分数）

对「公司是什么时候成立的？总部在哪里？」分别取阈值过滤前后分数：

| 切片 | 相似度 | 是否越过阈值 0.485 |
| :--- | :--- | :--- |
| 「三、发展历程」~「四、组织架构」 | 0.5062 | 是（命中，只含成立时间） |
| 「一、公司概况」~「二、主营业务」（含总部地址） | 0.4675 | **否（被过滤）** |

结论：生成侧行为正确（v1.1 已如实说明"片段中未提及总部所在地信息"），但**表格式切片**（Markdown 表格 / Excel）
与自然语言问题的语义相似度系统性偏低，阈值 0.485 会滤掉它们。建议第 3 周随 Rerank 一起处理。

### 3.3 QA-015 多轮追问存在"提前展开 + 重复"

第 1 轮"试用期员工有年假吗？"已包含转正后的折算规则；第 2 轮"那转正之后呢？"又重复了折算规则。
Prompt v1.1 新增的"不提前回答未提出的追问、同一会话内不重复"两条规则**未完全生效**（模型倾向一次答全）。
多轮追问是第 3 周正式交付项（FR-QA-05），建议与"历史压缩 + 问题改写"一并解决。

### 3.4 正面结论

- 拒答链路表现突出：5/5 正确、零编造，且**阈值过滤后直接兜底、不调用大模型**（12ms）——M-04 核心亮点成立；
- 表格三档类问题（住宿/餐补/通讯补贴）回答完整、位置引用正确，说明结构化切片对**字段明确**的表格有效；
- 全部 20 条问答未出现任何数字与原文不符的情况（自动比对数字集合 100% 命中）。

## 5. 复现步骤

```bash
# 1) 重建知识库（约 1 分钟，需已下载本地 Embedding 模型）
python scripts/init_kb.py --rebuild

# 2) 首轮评测（本次采用离线模式，与 /api/ask 共用检索服务与 Prompt；约 30 秒）
python scripts/eval_rag.py --mode offline --report docs/评测报告_v1.md

# 3) DEV 的 /api/ask 就绪后切换为接口模式，口径不变
python scripts/eval_rag.py --mode api --base-url http://127.0.0.1:8000
```
