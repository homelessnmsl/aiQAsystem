## 四、风险登记（PM维护）

| 风险 | 等级 | 应对 |
| :--- | :--- | :--- |
| 成员环境不一致导致联调失败 | 中 | 统一 Python 3.12、requirements.txt 锁定版本、共用 .venv 约定 |
| API Key 泄露 | 高 | .env 不入库，只用 .env.example 占位；发现即轮换 |
| RAG 检索质量不达标 | 高 | 第3周专项优化（Rerank+调参），PE 提前建测试集量化 |
| 进度滞后 | 中 | 每周两次同步会，Issue 上透明化进度，滞后>2天组长介入 |
| 答辩演示翻车 | 中 | 第4周至少两次彩排 + 本地备份演示视频 |
