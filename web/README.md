# web/ —— 前端（Streamlit，UI 主责）

- 契约依据：`docs/接口文档.md` 第 4 章（联调约定与错误码映射）
- 只通过 HTTP 调后端（`WEB_API_BASE`），**禁止** import 后端代码或直连数据库

| 文件 | 职责 | 交付周 |
| :--- | :--- | :--- |
| `app.py` | 问答页（提问框、对话流、引用折叠、反馈按钮） | 第1周骨架（W1-18）→ 第2周联调 |
| `pages/1_知识库管理.py` | 上传区、上传进度、文档列表、删除 | 第2周 |
| `components/` | 引用卡片、状态提示（加载/空/错误）等复用组件 | 第2~3周 |
| `api_client.py` | 统一封装 requests 调用与异常兜底（参考接口文档 4.1） | 第1周 |

启动：`python -m streamlit run web/app.py`（默认 http://127.0.0.1:8501）

要求（FR-UI-01/03）：加载态"正在检索知识库…"、空态"请先上传文档"、错误态中文提示且**不显示 Python 报错堆栈**。
