# Few-shot 示例（v1，默认不启用）

用途：第 2 周联调时若出现「引用遗漏」「表格漏档位」「兜底不彻底」三类问题，按需追加到系统提示词之后，或以 user / assistant 消息对注入。

## 启用建议
1. 默认不启用：省 token，且评测集事实点集中，few-shot 容易让模型过度模仿示例句式。
2. 仅当第 2 周首轮评测满足以下任一条件时启用：引用缺失率 > 15%，或表格题漏档位 ≥ 2 条，或拒答题出现编造。
3. 以下示例来自**虚构的示例企业**，与真实知识库数据无关；启用时保留该说明，避免模型套用示例中的数字。
